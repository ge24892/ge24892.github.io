{#- Language switcher. Renders one link per *other* configured language. The link points to the same content in that language when a translation exists, and falls back to that language's home page otherwise (e.g. a post that only exists in English). `config.languages` only contains the languages other than the active one, and `translations` (on a page or a section) only contains languages that actually have a translation.
